# 宴会厅的黄昏 · Banquet Dusk

Wallpaper Engine **Web 壁纸工程**（type = web）。原图 `bg.jpeg`（2880×1440）被做成了会呼吸的黄昏宴会厅：
阳光从左侧斜射进来，光柱在空气里缓慢明灭，尘埃只在被照亮的地方浮出来，后墙三扇窗的日落光像云过一样呼吸，
窗内远处城市灯火闪烁，前景的暖雾 / 暗角 / 胶片颗粒比照片移动得更多，于是画面有了纵深。

## 目录结构

```
banquet-dusk/
├── project.json      Wallpaper Engine 工程描述（类型 web、预览图、10 个用户属性）
├── index.html        页面骨架（分层容器）
├── styles.css        分层的样式：光柱、窗户光、暗角、颗粒、冷调
├── main.js           运行时：视差与呼吸、粒子、音频、用户属性
├── assets/bg.jpg     原图（工程自包含，不依赖绝对路径）
└── preview.jpg       1920×1080 的工程预览图
```

## 在 Wallpaper Engine 里打开

1. 打开 Wallpaper Engine → 打开壁纸编辑器。
2. 编辑器菜单里的“打开工程 / Open Project”，选择本文件夹中的 `project.json`。
   （也可以先把整个 `banquet-dusk` 文件夹复制到 Steam 的
   `steamapps/common/wallpaper_engine/projects/myprojects/` 下，再在编辑器里打开。）
3. 编辑器里直接就是最终效果；点“应用”即可设为桌面壁纸。

不装 Wallpaper Engine 也能看效果：直接用 Chrome 打开 `index.html` 即可（所有效果除音频联动外都正常）。
注意工程是 CEF 页面，用 `file://` 打开时不要开 `--disable-web-security` 之类参数，Wallpaper Engine 自己会用本地 http 服务托管。

## 属性面板里能调什么

| 属性 | 默认 | 作用 |
| --- | --- | --- |
| 氛围强度 | 100 | 所有氛围层的总强度（光晕、尘埃、暖雾、颗粒） |
| 光线强度 | 100 | 只影响光柱与窗外光，调到 0 就是干净的原图 |
| 柔光强度 | 100 | 窗框外溢光晕、全屏暖色呼吸、提灯亮度 |
| 视差强度 | 100 | 鼠标移动时各层位移的幅度（0 = 完全静止） |
| 全景滚动 | 开 | 画面被裁得太多时沿该方向缓慢往返，看到整张图 |
| 滚动速度 | 100 | 一个完整往返的时长，调 0 就固定在当前一侧 |
| 光线颜色 | 暖橙 | 所有光的色相，换成冷蓝就是雪夜窗景 |
| 尘埃粒子 | 开 | 空气中的漂浮微粒 |
| 画面呼吸 | 开 | 极缓慢的推拉与平移，让静图“活着” |
| 随音乐起伏 | 开 | 有音频时低频带起光线与尘埃（Wallpaper Engine 提供音频数据） |

## 氛围是怎么做出来的

- **标定对齐**：先用 canvas 逐像素扫描原图，量出三扇窗的玻璃范围（x 33.4–40.7 / 45.3–54.3 / 59.3–66.4、y 从 24.4 起，
  窗内地平线 y≈35）、左墙主光带（x 0–4、y 2–41）、地面光斑（y 92–100、x 8–20）。所有光效都按这些坐标贴在真实光斑上，
  而不是随便铺一层发光。
- **视差**：照片层基础放大 1.055 留出余量，鼠标位置经缓动后驱动位移；尘埃 ×1.35、暖雾 ×1.6、暗角 ×1.9
  （都是相对照片层的倍数），近处层动得更多，于是有了前后关系。
- **全景滚动（看到整张图）**：原图是 2:1，屏幕比它窄的时候左右两侧就会被切掉（16:9 切掉约 16%，4:3 切掉约 33%，
  竖屏能切掉七成）。只要某个方向上被切掉的比例超过 8%，画面就沿该方向缓慢往返，一个周期（默认 96 秒）走完整个隐藏范围，
  所以任何比例下都能在一段时间里把整张图看全。节奏是“两端各停留一会儿、中间平滑扫过”，鼠标一动降速到 12%、
  静止 1.2 秒后恢复，不会跟你正在看的地方抢镜头。两个方向各判各的：16:9 只会左右滚，21:9 派生的是上下滚。
  滚动与视差共用同一份余量（滚动范围 = 可用余量 − 视差留白），再怎么滚也不会露出画面外的空白边。
- **呼吸**：推拉 ±0.6%、平移 ±0.5%，周期 39s / 47s / 61s 互质，看不出循环。
- **烛光**：三个不同频率的正弦叠加成 1% 上下的亮度抖动，加上全屏暖色叠加层的缩放呼吸。
- **合成方式**：光柱、窗光、尘埃、暖雾都用加色（screen / lighter）叠加，只加光不改变原图内容，
  所以不会出现图层错位或切割痕迹。漏光雾与暗角属于镜头效果，只随鼠标视差轻微移动、不跟着全景滚动跑；
  尘埃则与画面一起移动（在画布外换位，屏幕上看不到跳变）。

## 性能

单张静态图 + 12 个模糊发光层 + 一个最多 100 粒的 canvas + 220×124 的颗粒画布（每 3 帧刷新一次）。
页面隐藏时会停止渲染（Wallpaper Engine 切换壁纸后不占资源）；像素比上限 1.5，4K 屏下不会成倍扩大开销。

## 说明

- 本工程是 **Web 类型**，可以手写、可读可改。用编辑器“创建”出来的是 Scene 类型（`scene.pkg` 二进制格式），
  无法手写，所以这里用 Web 类型实现同样的氛围，并且更容易调参。
- 原图是单张平面图，没有分层蒙版，因此没有做“切开人物做硬视差”的效果——那样会在轮廓上露馅；
  纵深是靠前景光雾 / 暗角 / 尘埃的分层位移做出来的。
- 音频联动只在 Wallpaper Engine 里生效（`wallpaperRegisterAudioListener`），浏览器里会自动忽略。
