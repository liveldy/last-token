    关于与数据来源

    左边是按厂商着色的能力-成本散点图，只画综合能力最靠前的那些模型；右边是全部模型的排行榜。 两边的序号是同一个：点图上的点会跳到榜上那一名并把它点亮，点榜单的行会打开它的详情。

    综合能力怎么来的

    取 ZeroEval / LLM Stats 的 general 分类指数：把各家在各项基准上的成绩放进同一套 TrueSkill 模型里比出来的分数，报告值是保守估计 μ − 3σ，所以基准跑得少的模型会被压得低一些， 不会靠一两个高分冲上去。

    参考成本怎么算的

    横轴是每百万 token 的加权美元价，输入 : 输出 = 3 : 1。输入输出价都取自 ZeroEval 收录的官方标价； 它没收录的，退回 OpenRouter 的公开价。缓存命中、思考预算与批量折扣都会让实际账单更低或更高。
