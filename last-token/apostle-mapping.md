# 座位表对照：列奥纳多的《最后的晚餐》与《最后的 Token》

这份文档做两件事：先把原作**画的是哪一刻、谁坐在哪里、手在做什么**拆开，再把二创的 13 位角色
逐位放回那 13 个位子上，看每个模型的位置和原画之间是什么关系。

- 原画部分的身份与手势，沿用艺术史通行的读法（见文末〈核对方法〉）。
- 二创部分的手势，是把 `bg.jpeg` 分段放大后**逐位读图**得到的，不是猜的；文末附了每段读到了什么。
- 二创是 AI 生成的同人画作，座位与手势的对齐很可能是构图控制（img2img / ControlNet 一类）带来的，
  未必是逐条隐喻设计。所以〈四〉里那些「位置 ↔ 厂商性格」的对应，是**读图得到的联想**，
  不是作者声明——当作一种解读来看，别当作考据结论。

## 一、原作：列奥纳多画的是哪一刻

米兰圣玛利亚感恩教堂的食堂北墙，约 1495–1498 年，460 × 880 cm。用的是蛋彩与油彩直接画在
**干**墙面上，不是真正的湿壁画，所以壁画还没干透就开始剥落，五百年来修了又修。

**画的是哪一秒。** 不是「这是我的身体」那一秒，而是约翰福音 13:21 之后的一秒：
耶稣说完「你们中间有一个人要卖我了」，十二个人同时炸开。列奥纳多整幅画都在画**这句话的回声**。

**三条让画面钉住的线。**

1. **透视的灭点**落在耶稣右侧太阳穴附近，全部桌沿、天花板格、后墙壁画都朝它收敛。
   所有人的头大致落在同一条水平线上——这就是为什么它看起来这么「平」。
2. **耶稣是全画唯一的静止点**。十二个人都在动，只有他一动不动，身体构成一个正三角形，
   双手摊开、掌心向上，一手对着面包、一手对着酒杯。
3. **没有光环**。列奥纳多去掉了传统的圣光，只用身后那扇**正对着他头的窗**和黄昏的天光替他加冕。

**四组人，像四道从中心扩散出去的波。** 十二门徒被编成左右各两组、每组三人：

```
        巴多罗买 ┐  ┌ 犹大      ┌ 耶稣 ┐  ┌ 多马      ┌ 马太
        雅各(小) ├左┤ 彼得      │      │  ├ 雅各(大) ├右┤ 达太
        安得烈   ┘  └ 约翰      └      ┘  └ 腓力     ┘  └ 西门
```

自左至右的通行读法与各自的手：

| # | 人物 | 在这一刻做什么 |
| --- | --- | --- |
| 1 | 巴多罗买 | 坐在最外端，两手撑在桌沿，半侧身，目光越过来看耶稣 |
| 2 | 亚勒腓的儿子雅各（「小雅各」） | 夹在巴多罗买与安得烈之间，左手越过安德烈的背去搭彼得的肩 |
| 3 | 安得烈 | **双手举到胸前、掌心朝外**，像在说「等等」「不是我」；他是把「五饼二鱼」带给耶稣的那个人 |
| 4 | 加略人犹大 | **手里攥着钱袋**，身体向外倾、肘撑在桌上，脸是全画唯一落在阴影里的；传统上也说他肘边翻倒了一只盐罐 |
| 5 | 彼得 | 冲动的那一个：身体前倾越过犹大，**左手搭在约翰肩上**，右手藏在身后**握着一把刀** |
| 6 | 约翰 | 最年轻、无须，「耶稣所爱的那门徒」——**双手交握**、头垂向一侧，紧挨着耶稣 |
| 7 | **耶稣** | 中心、静止、垂眼，双手摊开掌心向上，覆在面包与酒杯上 |
| 8 | 多马 | **竖起一根食指**（后来「怀疑的多马」的经典手势），额头皱着 |
| 9 | 西庇太的儿子雅各（「大雅各」） | **双臂张到最开**、掌心朝外；他和约翰外号叫「雷子」，也是第一个殉道的门徒 |
| 10 | 腓力 | **双手按在胸口**，身体前倾问「主啊，是我吗」；福音书里那两句算账的话（二百银币的饼、求看父）都是他说的 |
| 11 | 马太 | **两手朝耶稣那边指**——税吏出身，画里最像「记账的人」 |
| 12 | 达太 | 手掌摊开、掌心向上，一脸没听懂 |
| 13 | 奋锐党的西门 | 坐在最外端，**两手摊开**；「奋锐党」是当时最激进的政治派别 |

桌子两端都被画面裁断——故事还在继续，人还在往里坐。

## 二、二创把座位表怎么搬过来的

`bg.jpeg`（2880×1440）里 13 个立绘，一对一站进上面 13 个位子：**顺序不换，左右不镜像，
分组也不变**（3 + 3 + 主位 + 3 + 3）。标定坐标写在 `data/model-data.js` 的 `CHARACTERS` 里：

```
10 · 16 · 21.5   |   29 · 35.5 · 40.5   |   48.5   |   60.5 · 65 · 71.5   |   82.5 · 88.5 · 95
   DeepSeek  Qwen  Llama   Seed  Grok  Kimi   GPT     Perplexity Gemini Claude   Mistral GLM 文心
   = 巴多罗买 小雅各 安得烈  犹大  彼得  约翰   耶稣     多马    大雅各  腓力    马太   达太 西门
```

两组之间的**间距**也被复制了：主位两侧各留出一段空白（40.5 → 48.5 → 60.5，左右各空 8% 与 12%），
这是全图唯一的「留白」，把主位从人群里摘出来——原作里耶稣的孤立感是靠两侧门徒后仰的姿势得到的，
二创直接改成了物理空隙。

中央五个人的一整段，主位那颗头**仍然正对着中间那扇窗**——灭点没动。

## 四、这张座位表读出来的几件事

1. **主位不是给分数最高的。** Claude 是 #1，但它坐在第 10 位；主位给的是 #3 的 GPT。
   座次是按「谁是这一屋子的原点」排的，不是按榜单——十三个人里有十二个的视线朝向中央那一颗头。
2. **最强的三个人紧贴着主位的右边。** 主位右侧（8/9/10 位）是全图分数最密的一段：
   GPT #3、Gemini #4、Claude #1。主位的左侧（4/5/6 位）则是挑战者段落：
   Kimi #14、Grok #37、Seed #40。右边是「守着前沿的人」，左边是「掀桌子的人」。
3. **拿钱袋的位子给了最便宜的那一家。** 犹大的钱袋落在 Seed 手上，是全图最直接的一次「移花接木」。
4. **唯一没有名次的人，坐在怀疑者的位子上。** 多马要证据，Perplexity 给引用；它也是十三个人里
   唯一进不了 ZeroEval general 榜的。
5. **版本最多的人坐在「主持者」的位子上。** Qwen 有 58 个版本，对应的小雅各是留在耶路撒冷
   主持教会的那一个——留在原地、被最多人接着用的角色。
6. **两端的位子最弱。** 最右端那一组（Mistral #39、GLM #16、文心 #121）平均名次是四组里最低的；
   最左端那一组（DeepSeek #15、Qwen #17、Llama #12）反而是稳的中段。用「越靠边越弱」读整张图不准，
   真正的分界线是**主位左右那一道**。
7. **窗跟着主位。** 原作把三扇窗收在耶稣身后当光环用，二创把窗拉成一整段，但主位那颗头
   仍然正好落在中间那扇窗里——灭点、光源、视线，三样都还指着同一个位子。

## 五、二创没有照搬的地方

- **犹大的阴影脸没搬。** 原作里犹大是唯一一个脸落在暗处的人，二创里 Seed 是正常打光的。
  也就是说「钱袋」这层符号被保留了，「阴影」这层被丢掉了——所以「Seed = 叛徒」这个读法，
  证据只有一只手，不算充分。
- **三扇半圆窗变成了一整排落地窗**，两旁的红壁毯与烛台照旧（原作两端也是挂毯墙）。
- **原作的象征小物件没跟过来**：彼得身后那把刀、犹大肘边的盐罐，在二创的桌面上都找不到；
  桌上换成了通用的面包、葡萄、石榴、橄榄枝。
- **桌子被拉长了。** 原作的桌子两端被画框裁掉，暗示人还在往里坐；二创把 13 个立绘完整收进画面，
  两端各留出一点空气。
- 主位那一侧原作是**一对**（面包与酒杯），二创把它铺成了一整盘面包加两只金杯，更接近「宴会」而不是「圣餐」。

## 六、读法上的保留

- 座位与手势的对齐非常整齐（13 处里有 6 处是「一模一样地照抄」：举手、钱袋、搭肩、垂眼摊手、
  竖食指、按胸口），这更像是**构图控制**——即二创是以原作为构图参考生成的——而不是逐位设计隐喻。
  所以〈三〉〈四〉里的对应关系，读法是「这个位子在原叙事里是什么意思，坐上去的人像不像」，
  不是「作者想说什么」。
- 原画的人物身份沿用艺术史通行读法（十九世纪以来对摹本的比对结论），个别身份
  （巴多罗买 / 达太 / 西门）在不同文献里仍有出入。
- 分数与价格取 `data/models-snapshot.js` 里 2026-10-22 的快照；榜单是会变的，
  座位表不会——所以这张图更像是对某一时刻的画像。

## 附：核对方法

原画的手势描述来自艺术史通行读法与对原作的观察；二创的手势是把 `bg.jpeg`（2880×1440）按
`CHARACTERS` 的 `x` 坐标分成四段、放大 1.5–2.4 倍后逐位读出来的，读到的原话如下：

- **第 1 段（x 180–1200：DeepSeek / Qwen / Llama / Seed / Grok / Kimi）**：DeepSeek 手扶桌沿、
  身体朝里；Qwen 站在她身后、手放桌边；**Llama 双手举到胸前、掌心朝外**；
  **Seed 手上捧着一只棕色布袋、压在桌上**；**Grok 从后面探身，右手搭在旁边银发角色的肩背上**；
  Kimi 双手交握搁在桌上、头低着。
- **第 2 段（x 760–1740，放大重看）**：确认 Grok 的手落在 Kimi 肩上；Seed 手里的布袋口扎着绳；
  GPT 双臂平摊、掌心朝上，身前是面包盘、金杯与橄榄枝；**Perplexity 竖着一根食指**。
- **第 3 段（x 1270–2050：GPT / Perplexity / Gemini）**：GPT 闭眼、微笑、双手摊在桌面高度；
  Perplexity 食指竖起；**Gemini 两手张开、掌心朝外**。
- **第 4 段（x 1940–2880：Claude / Mistral / GLM / 文心一言）**：**Claude 两手按在胸前**；
  Mistral 一手抬起朝画面中央指；GLM 手掌摊开；文心一言两手摊开，坐在轮椅里、位于最外端。
