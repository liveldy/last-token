# 模型能力图鉴 · Wallpaper Engine 壁纸版

同目录下 `../model-atlas` 那个网页的**壁纸版本**：一样的能力 - 成本散点图、一样的 395 个模型排行榜、
一样点一下就能互相跳转、点开看详情，区别只在于它按壁纸来活——**没人碰的时候，屏幕上只有图**，
而且安静下来之后它会自己按节奏轮流点亮榜上的模型。

```
model-atlas-we/
├── project.json           Wallpaper Engine 工程描述（web 类型、预览图、9 个用户属性）
├── index.html             页面骨架（比网页版多一行 MODEL_ATLAS_WALLPAPER 标记与 wallpaper.js）
├── styles.css             氛围层样式 + 界面样式（含壁纸模式的浮层收起规则）
├── ambience.js            氛围运行时：光晕、点阵、暗角、颗粒、鼠标视差
├── app.js                 交互层：散点图、排行榜、详情弹窗（壁纸模式走 idle 与自动巡览那条分支）
├── wallpaper.js           把属性面板接到画面层的 settings 上
├── data/                  数据快照与数据集构建逻辑
├── tools/build-data.cjs   重新拉取数据生成快照
└── preview.jpg            1920×1080 工程预览图
```

## 在 Wallpaper Engine 里打开

1. 打开 Wallpaper Engine → 打开壁纸编辑器。
2. 菜单里的「打开工程 / Open Project」，选择本文件夹中的 `project.json`。
   （也可以先把整个 `model-atlas-we` 复制到 `steamapps/common/wallpaper_engine/projects/myprojects/` 下再打开。）
3. 编辑器里直接就是最终效果，点「应用」设为桌面壁纸。

不装 Wallpaper Engine 也能看：直接用 Chrome 打开 `index.html`。这时没有属性面板，
其余效果（含鼠标交互与自动巡览）都在，浮层依旧会自己收起来。注意工程是 CEF 页面，
用 `file://` 打开时不要加 `--disable-web-security` 之类的参数。

## 作为壁纸时的行为

- **没人动**：顶栏与底部提示条在鼠标停下 5 秒后淡出，桌面只剩图——两团很慢的光晕、一层淡点阵、
  暗角与胶片颗粒，鼠标移动时有极轻微的视差。
- **安静下来之后**：停手 22 秒起，每 `max(2, 7 × 巡览节奏)` 秒自动换一个模型高亮——
  图上的点加圈、右侧榜单滚到那一名并点亮，于是一整面数据图自己会动。
- **鼠标一动**：浮层淡回，点与行重新可点，自动巡览暂停 22 秒再继续。
- **点图上的点** → 榜单跳到那一名并点亮；**点榜单任意一行** → 弹出详情（综合能力卡、
  最多 24 条基准记录、规格、官方标价与工作量估算、同厂商其它模型、数据出处）。
- 属性面板里把「可点模型档案」关掉，就只剩自动巡览在换高亮，鼠标再划过也不会打开任何东西。
- 屏幕窄的时候（竖屏等）自动改成上下排布：图在上、榜在下。

## 属性面板

| 属性 | 默认 | 作用 |
| --- | --- | --- |
| 氛围强度 | 100 | 背景两团光晕、点阵与胶片颗粒的总强度 |
| 柔光强度 | 100 | 只影响光晕与暗角，调到 0 背景就是干净的纯色 |
| 画面呼吸 | 开 | 光晕与点阵极缓慢地漂移，关掉则完全静止 |
| 能力图画多少个点 | 50 | 图上画综合能力最靠前的多少名（20–150，只数有公开标价的） |
| 自动巡览 | 开 | 安静之后轮流点亮榜上的模型 |
| 巡览节奏 | 100 | 数值越大换得越慢（2–21 秒一个） |
| 强调色 | 蓝 #4285f4 | 界面强调色、选中环与中位线的颜色 |
| 浅色主题 | 关 | 关掉是纯黑背景，打开切到浅色界面 |
| 可点模型档案 | 开 | 关掉后点与行都不再响应鼠标，只剩自动巡览 |

## 数据

打包在 `data/models-snapshot.js` 里，**壁纸不联网**，直接读工程内置快照：
395 个模型的 ZeroEval general 综合能力与全局排名、其中 175 个的公开标价，
以及每个模型的版本、发布日、上下文、参数量、协议与各基准分。要更新：

```bash
node tools/build-data.cjs      # 需要本机 Node，拉 ZeroEval 与 OpenRouter 的公开接口
```

参考成本按 `(3 × 输入价 + 输出价) / 4` 美元 / 百万 token 加权；两个接口都不发 CORS 头，
但壁纸不需要联网，所以没有代理也不影响。

## 与网页版的关系

`../model-atlas` 是同一份页面的「网站版」，本目录是从它复制出来的、自包含的壁纸工程：
`styles.css`、`ambience.js`、`app.js`、`data/`、`tools/build-data.cjs` 内容完全相同
（改完用 `cmp` 复核一遍，必须逐字节一致）。差别只有三处——多一行 `MODEL_ATLAS_WALLPAPER` 标记、
多一个 `wallpaper.js`、多一份 `project.json` 与 `preview.jpg`。`app.js` 与 `ambience.js` 里
壁纸相关的分支都在 `WALLPAPER` 这个开关后面，普通浏览器打开时等于不存在。
