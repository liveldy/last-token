# 最后的 Token · Wallpaper Engine 壁纸版

同目录下 `../last-token` 那个网页的**壁纸版本**：一样的黄昏宴会厅、一样可以点开角色看数据，
区别只在于它按壁纸来活——**没人碰的时候，屏幕上只有画面**，鼠标一动才浮出提示与按钮。

```
last-token-we/
├── project.json           Wallpaper Engine 工程描述（web 类型、预览图、10 个用户属性）
├── index.html             页面骨架（比网页版多一行 LAST_TOKEN_WALLPAPER 标记与 wallpaper.js）
├── styles.css             画面氛围层样式 + 界面样式（含壁纸模式的浮层收起规则）
├── ambience.js            画面运行时：呼吸、视差、拖动画面、尘埃、颗粒、音频、聚焦
├── app.js                 交互层：角色热区、档案面板（壁纸模式走 idle 自动收起那条分支）
├── wallpaper.js           把属性面板接到画面层，并处理“可点角色档案”开关
├── assets/bg.jpg          原图 2880×1440
├── data/                  角色标定 + 数据快照
├── tools/build-data.cjs   重新拉取数据生成快照
└── preview.jpg            1920×1080 工程预览图
```

## 在 Wallpaper Engine 里打开

1. 打开 Wallpaper Engine → 打开壁纸编辑器。
2. 菜单里的“打开工程 / Open Project”，选择本文件夹中的 `project.json`。
   （也可以先把整个 `last-token-we` 复制到 `steamapps/common/wallpaper_engine/projects/myprojects/` 下再打开。）
3. 编辑器里直接就是最终效果，点“应用”设为桌面壁纸。

不装 Wallpaper Engine 也能看：直接用 Chrome 打开 `index.html`。这时没有属性面板与音频联动，
其余效果（含鼠标交互）都在，浮层依旧会自己收起来。注意工程是 CEF 页面，用 `file://` 打开时
不要加 `--disable-web-security` 之类的参数。

## 作为壁纸时的行为

- **没人动**：画面按自己的节奏呼吸、卷动、飘尘；浮层（右上角两个按钮、底部提示条）在鼠标停下 5 秒后淡出，
  桌面上只剩画。档案面板若开着，一分半没人碰会自动收起。
- **鼠标一动**：提示条与按钮淡回，角色热区可点；点开角色时，画面会把她缓移到面板对面那一侧，不挡住本人。
- **键盘**：`Tab` 走遍 13 位角色，`Enter` 打开，`←` `→` 切换角色，`Esc` 关闭。
- 属性面板里把“可点角色档案”关掉，就是一张纯氛围壁纸，鼠标划过不再有任何反应。

## 屏幕比例与拖动

原图是 2:1（2880×1440），屏幕比它窄的时候（16:9 会切掉左右各约 8%，4:3 更多，竖屏能切掉七成）。
画面**不会自己移动**：按住鼠标左键左右拖——上下被裁掉时同样可以上下拖——触摸屏上直接用手指划，
就能把被裁掉的部分拉进视野，两端的人物也就随时都能看到。

- 只认**鼠标左键**，右键留给系统菜单；多指时只跟第一根手指。
- 拖动范围是“可用余量 − 视差留白”，拖到头就停住，不会露出画面外的空白边。
- 松手后画面**停在原处**，只顺着最后的势头滑一小段（约一百多像素）就彻底停住；停手超过 90 毫秒
  再松开则完全不带惯性。
- 拖动被当作一次拖动而不是点击：拖完那次 `click` 会被吞掉，不会顺手打开角色档案；
  真正单击角色照旧打开档案。
- 不想让人拖：属性面板里关掉「拖动查看全图」，画面就固定在正中。

## 属性面板

| 属性 | 默认 | 作用 |
| --- | --- | --- |
| 氛围强度 | 100 | 所有氛围层的总强度（光晕、尘埃、暖雾、颗粒） |
| 光线强度 | 100 | 只影响光柱与窗外光，调到 0 就是干净的原图 |
| 柔光强度 | 100 | 窗框外溢光晕、全屏暖色呼吸、提灯亮度 |
| 视差强度 | 100 | 鼠标移动时各层位移的幅度（0 = 完全静止） |
| 拖动查看全图 | 开 | 关掉后画面固定在正中，鼠标拖动不再移动画面 |
| 光线颜色 | 暖橙 | 所有光的色相，换成冷蓝就是雪夜窗景 |
| 尘埃粒子 | 开 | 空气中的漂浮微粒 |
| 画面呼吸 | 开 | 极缓慢的推拉与平移，让静图“活着” |
| 随音乐起伏 | 开 | 有音频时低频带起光线与尘埃 |
| 可点角色档案 | 开 | 关掉后热区不再响应，成为纯氛围壁纸 |

## 点开角色能看到什么

每个角色对应一个模型家族，面板里列的是这个家族**每个版本**的综合能力与参考成本：

- **综合能力** = ZeroEval general 指数（`api.zeroeval.com/leaderboard/indexes/all`），395 个模型同一标尺下的
  TrueSkill 保守估计（μ − 3σ），带全局名次。
- **参考成本** = 官方标价（美元 / 百万 tokens），并按“一次长对话 / 一份长报告 / 批量 100 万 tokens”三个
  示例工作量估算，中文按 1 token ≈ 1.5 个汉字折算。
- **Perplexity** 这一族 ZeroEval 没有收录，只给 OpenRouter 的价格，并注明没有可比的基准分。

数据打包在 `data/models-snapshot.js` 里（壁纸不联网，直接读工程内置快照）。要更新：

```bash
node tools/build-data.cjs      # 需要本机 Node，拉 ZeroEval 与 OpenRouter 的公开接口
```

## 与网页版的关系

`../last-token` 是同一份页面的“网站版”，本目录是从它复制出来的、自包含的壁纸工程：`styles.css`、
`ambience.js`、`app.js`、`data/`、`assets/` 内容相同，差别只有三处——多一行 `LAST_TOKEN_WALLPAPER` 标记、
多一个 `wallpaper.js`、多一份 `project.json` 与 `preview.jpg`。改了网页版里那几个共用文件，把对应文件
复制过来即可；`app.js` 里壁纸相关的分支都在 `WALLPAPER` 这个开关后面，普通浏览器打开时等于不存在。
